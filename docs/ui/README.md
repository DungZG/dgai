# dgai — UI redesign brief

Tài liệu này là nguồn duy nhất để agent thiết kế (pendev) đọc trước khi đổi giao diện.

- `inventory-user.md` — mọi màn hình và popup phía người dùng
- `inventory-admin.md` — mọi màn hình và popup phía quản trị
- `prompt.md` — prompt gửi thẳng cho agent thiết kế

Quy ước: mỗi màn hình ghi route + file; mỗi popup ghi component + file + trigger.
